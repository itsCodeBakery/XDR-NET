# BaseLineExperement

## Purpose

Baseline model implementations and their per-model code, plots, result tables/predictions and dataset split files. The directory name is retained as stored.

The manuscript comparisons use common evaluation conditions, but architecture-specific tuning may differ. Treat results as controlled-baseline comparisons, not proof of globally optimal baseline performance.
